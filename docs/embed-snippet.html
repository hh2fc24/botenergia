EnergyBot Embed

1) Iframe directo (simple)

Pega esto en WordPress (bloque "HTML personalizado"). Reemplaza TU_DOMINIO.
Nota: en este formato el pageUrl queda fijo. Recomendado usar el snippet con script. 

<iframe
  src="https://TU_DOMINIO/embed?open=1&theme=light&pageUrl=https%3A%2F%2Fexample.com%2Fmi-pagina"
  style="position:fixed;right:16px;bottom:16px;width:390px;height:620px;border:0;z-index:2147483000;"
  title="EnergyBot"
  loading="lazy"
></iframe>

2) Snippet con <script> (recomendado)

Inyecta un iframe flotante y pasa automáticamente la URL real de la página actual como pageUrl. Puedes cambiar el tema a dark. 

<script>
(function () {
  var BASE = 'https://TU_DOMINIO';
  var THEME = 'light'; // 'dark' | 'light'

  var src = BASE + '/embed'
    + '?open=1'
    + '&theme=' + encodeURIComponent(THEME)
    + '&pageUrl=' + encodeURIComponent(window.location.href);

  var iframe = document.createElement('iframe');
  iframe.src = src;
  iframe.title = 'EnergyBot';
  iframe.loading = 'lazy';
  iframe.style.position = 'fixed';
  iframe.style.right = '16px';
  iframe.style.bottom = '16px';
  iframe.style.width = '390px';
  iframe.style.height = '620px';
  iframe.style.border = '0';
  iframe.style.zIndex = '2147483000';

  document.body.appendChild(iframe);
})();
</script>
